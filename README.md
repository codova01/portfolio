## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/codova01/whosthis.git
cd whosthis
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

The development server will provide a local URL, usually:

```text
http://localhost:5173
```

Open the URL in your browser to view the portfolio locally.
